## 📖 核心知识点

### 1. 求职渠道

#### 1.1 主流求职平台

```
国内平台：

1. Boss 直聘
   - 优点：直接与 HR/技术负责人沟通
   - 适合：快速获得面试机会
   - 技巧：主动打招呼，展示技术能力

2. 拉勾网
   - 优点：互联网公司集中
   - 适合：互联网行业求职
   - 技巧：完善个人资料，突出项目经验

3. 猎聘
   - 优点：中高端岗位多
   - 适合：3 年以上经验
   - 技巧：与猎头建立联系

4. 脉脉
   - 优点：职场社交，内推机会多
   - 适合：获取内推
   - 技巧：活跃在技术圈子，建立人脉

5. LinkedIn（领英）
   - 优点：外企和国际化公司
   - 适合：外企求职
   - 技巧：英文资料，专业头像

外企平台：
- LinkedIn：全球通用
- Indeed：综合平台
- Glassdoor：公司评价和薪资

内推渠道：
- 前同事
- 技术社区朋友
- 开源项目贡献者
- 技术会议认识的人
```

#### 1.2 内推的价值

```
内推的优势：

1. 简历直达
   - 跳过 HR 初筛
   - 直接到技术负责人手中
   - 被看到的概率更高

2. 信任背书
   - 推荐人的信用背书
   - 面试官更重视
   - 可能跳过某些面试轮次

3. 信息优势
   - 了解岗位真实情况
   - 了解团队文化
   - 了解面试重点

如何获取内推：

1. 维护人脉
   - 与前同事保持联系
   - 参加技术社区活动
   - 贡献开源项目

2. 主动联系
   - 在脉脉/LinkedIn 找目标公司的人
   - 礼貌地请求内推
   - 提供完整的简历和目标岗位

3. 内推话术
   "您好，我是 XXX，目前在寻找 SRE 方向的机会。
    看到贵公司在招聘 SRE 工程师，我对这个岗位很感兴趣。
    不知道您是否方便帮我内推？我可以提供简历和详细信息。
    非常感谢！"

4. 内推后的跟进
   - 发送简历和目标岗位
   - 感谢对方的帮助
   - 及时告知面试进展
   - 如果成功，表达感谢
```

#### 1.3 投递策略

```
投递时间规划：

金三银四（3-4 月）：
- 年终奖发放后的跳槽潮
- 企业新财年招聘需求
- 建议：重点投递

金九银十（9-10 月）：
- 秋招 + 社招
- 年底冲业绩的招聘
- 建议：积极投递

其他时间：
- 5-8 月：相对淡季，但机会仍多
- 11-2 月：年底招聘减少，但竞争也小

每日投递计划：
- 投递数量：5-10 份精选简历
- 投递时间：上午 9:00-11:00
- 跟踪状态：建立投递进度表
- 及时回复：收到面试邀请后 24 小时内回复

投递进度表：
| 公司 | 职位 | 投递时间 | 状态 | 面试时间 | 备注 |
|------|------|---------|------|---------|------|
| 字节 | SRE  | 05-02   | 已投递 |         | 内推  |
| 阿里 | SRE  | 05-02   | 已约面 | 05-05   | 一面  |
| 腾讯 | SRE  | 05-03   | 已投递 |         | Boss  |

投递技巧：
1. 精准投递：根据 JD 定制简历
2. 主动沟通：投递后主动联系 HR
3. 保持耐心：7 天无回复可跟进
4. 广撒网：不要只投一家公司
5. 记录跟踪：记录每次面试的反馈
```

### 2. 面试流程

#### 2.1 面试前准备

```
面试前 Checklist：

1. 公司研究（1-2 小时）
   □ 了解公司业务和产品
   □ 了解公司技术栈
   □ 了解公司文化和价值观
   □ 了解最近的新闻和动态
   □ 准备 2-3 个问题问面试官

2. 技术准备（2-4 小时）
   □ 复习基础知识
   □ 准备项目介绍（STAR 法则）
   □ 准备系统设计题
   □ 准备算法题（如果需要）
   □ 准备行为面试题

3. 物资准备
   □ 打印 3 份简历
   □ 准备纸笔
   □ 准备证件（身份证）
   □ 确认面试地址/链接
   □ 测试网络和设备（线上面试）

4. 形象准备
   □ 着装得体（商务休闲）
   □ 整洁干净
   □ 准时到达（提前 10-15 分钟）

5. 心理准备
   □ 保持自信
   □ 放松心态
   □ 做好被拒绝的准备
   □ 把面试当作学习机会
```

#### 2.2 面试中的技巧

```
面试表现 Checklist：

1. 开场（前 5 分钟）
   □ 微笑、握手、问好
   □ 自我介绍简洁有力
   □ 展示积极的态度

2. 技术面试
   □ 听清问题再回答
   □ 不知道的诚实说不知道
   □ 展示思考过程
   □ 用具体例子说明
   □ 注意时间控制

3. 行为面试
   □ 使用 STAR 法则
   □ 准备具体案例
   □ 展示团队协作
   □ 展示解决问题的能力

4. 系统设计题
   □ 先澄清需求
   □ 画架构图
   □ 讨论权衡
   □ 考虑扩展性

5. 提问环节
   □ 准备 2-3 个有深度的问题
   □ 不要问薪资（留给 HR）
   □ 展示对岗位的兴趣

6. 结束
   □ 感谢面试官的时间
   □ 询问下一步流程
   □ 保持专业态度

面试禁忌：
❌ 迟到
❌ 着装不整
❌ 手机响铃
❌ 说前公司坏话
❌ 撒谎或夸大
❌ 不知道装知道
❌ 没有问题问面试官
```

#### 2.3 面试后的跟进

```
面试后 Checklist：

1. 当天
   □ 记录面试问题和自己的回答
   □ 记录面试官的反馈
   □ 评估面试表现
   □ 发送感谢邮件

2. 感谢邮件模板
   主题：感谢面试机会 - [你的姓名]

   [面试官姓名] 您好：

   感谢您今天抽出时间面试我。
   通过今天的交流，我对 [公司名] 和 [岗位名]
   有了更深入的了解，也更加期待能加入贵团队。

   面试中提到的 [某个技术点/项目] 让我印象深刻，
   我在 [相关经验] 方面有 [具体经验]，
   相信能为团队带来价值。

   如果有任何问题，请随时联系我。
   期待您的回复！

   此致
   敬礼

   [你的姓名]
   [联系方式]

3. 等待期间
   □ 继续投递其他公司
   □ 继续准备面试
   □ 不要只等一家公司

4. 收到反馈
   □ 如果通过：准备下一轮
   □ 如果未通过：请求反馈，总结经验
   □ 如果 Offer：评估和谈判
```

### 3. 谈薪技巧

#### 3.1 薪资谈判策略

```
谈判准备：

1. 了解市场行情
   - 查看薪资报告
   - 咨询猎头
   - 与同行交流
   - 查看招聘平台薪资范围

2. 评估自己的价值
   - 工作经验
   - 技术能力
   - 认证资质
   - 项目成果

3. 确定期望薪资
   - 最低接受薪资
   - 期望薪资
   - 理想薪资

谈判时机：
- 拿到 Offer 后再谈
- 不要主动透露期望薪资
- 让对方先出价

谈判话术：

场景 1：被问期望薪资
"我更关注岗位的发展机会和团队文化。
薪资方面，我希望能根据市场水平和我的经验来定。
请问贵公司这个岗位的薪资范围是多少？"

场景 2：拿到 Offer 后想提高
"感谢您的 Offer，我对这个岗位非常感兴趣。
不过，根据我的经验和市场水平，我希望能将薪资调整到 XX。
我有 XX 年经验，掌握 XX 技能，能为团队带来 XX 价值。"

场景 3：对方压价
"我理解贵公司的预算限制。
不过，根据我的经验和能力，我认为 XX 的薪资更合理。
如果薪资方面有困难，我们可以讨论其他补偿方式。"

场景 4：多个 Offer 竞争
"我目前有几个 Offer 在考虑中。
贵公司是我非常心仪的平台，但其他 Offer 的薪资更高。
如果贵公司能匹配到 XX，我会优先选择贵公司。"
```

#### 3.2 薪资构成解析

```
薪资构成：

1. 基本工资（Base）
   - 每月固定发放
   - 占总薪资的 60-70%
   - 是五险一金的基数

2. 绩效奖金
   - 季度或年度发放
   - 占总薪资的 10-20%
   - 与绩效考核挂钩

3. 股票/期权
   - 分期发放（通常 4 年）
   - 占总薪资的 20-40%
   - 有风险（股价波动）

4. 签字费（Sign-on Bonus）
   - 一次性发放
   - 通常 1-3 个月工资
   - 可能有退还条款

5. 年终奖
   - 年底发放
   - 通常 1-6 个月工资
   - 与公司业绩和个人绩效挂钩

6. 其他福利
   - 五险一金（公积金比例）
   - 补充医疗保险
   - 餐补、交通补
   - 健身、培训补贴

薪资谈判技巧：
1. 关注总包（Total Compensation）
2. 了解股票/期权的发放规则
3. 了解五险一金的缴纳基数
4. 了解年终奖的发放标准
5. 计算实际到手收入

总包计算公式：
总包 = 基本工资 * 12 + 年终奖 + 股票/年 + 签字费/4

示例：
基本工资：50K/月
年终奖：3 个月
股票：100 万/4 年
签字费：5 万

总包 = 50 * 12 + 50 * 3 + 100/4 + 5/4 = 600 + 150 + 25 + 1.25 = 776.25K
```

#### 3.3 如何评估 Offer

```
Offer 评估框架：

1. 薪资福利（权重 40%）
   - 总包金额
   - 基本工资比例
   - 股票/期权价值
   - 五险一金
   - 其他福利

2. 职业发展（权重 30%）
   - 技术栈和发展前景
   - 晋升空间
   - 学习机会
   - 团队氛围

3. 工作生活（权重 20%）
   - 工作强度
   - 加班文化
   - 通勤时间
   - 弹性工作

4. 公司前景（权重 10%）
   - 公司规模
   - 行业前景
   - 融资情况
   - 稳定性

评估表格：
| 维度     | 权重 | Offer A | Offer B | Offer C |
|---------|------|---------|---------|---------|
| 薪资福利 | 40%  | 8       | 9       | 7       |
| 职业发展 | 30%  | 9       | 7       | 8       |
| 工作生活 | 20%  | 7       | 6       | 9       |
| 公司前景 | 10%  | 8       | 9       | 7       |
| 加权得分 | 100% | 8.1     | 7.9     | 7.6     |

决策建议：
- 选择得分最高的 Offer
- 但也考虑直觉和感受
- 不要只看薪资
- 考虑长期发展
```

```
4. 生活准备
```

#### 4.2 入职后 30-60-90 天计划

```
入职后 30 天（学习期）：

目标：了解团队、熟悉环境、建立关系

行动：
- 了解团队成员和职责
- 熟悉公司技术栈和工具
- 学习业务知识
- 完成新人培训
- 建立良好的第一印象

关键指标：
- 认识团队所有成员
- 完成新人培训
- 能独立完成简单任务
- 建立基本的工作关系

入职后 60 天（贡献期）：

目标：开始贡献价值、参与项目

行动：
- 参与项目开发
- 提出改进建议
- 主动承担任务
- 建立技术影响力

关键指标：
- 参与 1-2 个项目
- 完成 3-5 个任务
- 提出 1-2 个改进建议
- 获得团队认可

入职后 90 天（独立期）：

目标：独立负责模块、成为团队一员

行动：
- 独立负责模块
- 参与技术决策
- 指导新人（如果有）
- 建立个人品牌

关键指标：
- 独立负责 1 个模块
- 参与技术评审
- 获得正面反馈
- 明确下一步发展方向
```

```
回答示例：

"我选择 SRE 方向有三个原因：

首先，我对系统架构和可靠性有浓厚的兴趣。
我喜欢研究系统是如何工作的，以及如何让它更稳定、更高效。

其次，SRE 是一个技术深度和广度兼具的领域。
它不仅需要扎实的技术基础，还需要系统性思维和解决问题的能力。
这正是我希望发展的方向。

最后，SRE 在现代软件工程中越来越重要。
随着系统规模的扩大，可靠性变得越来越关键。
我希望在这个领域深耕，为系统的稳定运行做出贡献。

在过去的学习中，我已经建立了 Linux、Docker、Kubernetes 等技术基础，
并且通过实践项目积累了经验。我相信这些准备能帮助我在 SRE 岗位上快速成长。"
```

```
回答示例：

"根据我的了解，这个岗位的主要职责包括：

1. 负责公司核心服务的可靠性保障
   - 建立和维护监控体系
   - 处理故障和事后复盘
   - 制定和执行 SLO

2. 推动自动化和平台化
   - CI/CD 流水线建设
   - 自动化运维工具开发
   - 内部平台建设

3. 跨团队协作
   - 与开发团队合作提升可靠性
   - 参与架构设计评审
   - 推动最佳实践

我对这个岗位非常感兴趣，因为：
- 它与我的技术栈高度匹配
- 它能让我在 Kubernetes 和云原生方向深入发展
- 它能让我参与大规模系统的可靠性建设

我相信我的技能和经验能为团队带来价值。"
```

### 3. "你有什么问题想问我们？"

```
好问题示例：

关于团队：
- "团队目前的规模和组成是怎样的？"
- "团队的技术栈和工具链是什么？"
- "团队的工作方式和文化是怎样的？"

关于岗位：
- "这个岗位的主要挑战是什么？"
- "这个岗位的考核标准是什么？"
- "这个岗位的发展路径是怎样的？"

关于技术：
- "目前系统面临的最大技术挑战是什么？"
- "团队在可观测性方面有哪些实践？"
- "团队在自动化方面有哪些规划？"

关于公司：
- "公司对 SRE 的重视程度如何？"
- "公司未来的技术发展方向是什么？"
- "公司的培训和学习资源有哪些？"

避免的问题：
❌ "薪资是多少？"（留给 HR）
❌ "加班多吗？"（显得不够投入）
❌ "公司有什么福利？"（显得只关心利益）
```
