## 📖 调度机制

### 1. 调度流程

```
Pod 创建 → API Server → etcd
  → Scheduler 监听未调度的 Pod
  → 过滤（不满足条件的节点）
  → 打分（最优节点）
  → 绑定 Pod 到节点
  → kubelet 创建容器
```

### 2. nodeSelector

```yaml
spec:
  nodeSelector:
    disktype: ssd
    zone: us-east-1a
```

### 3. nodeAffinity

```yaml
spec:
  affinity:
    nodeAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
        nodeSelectorTerms:
          - matchExpressions:
              - key: disktype
                operator: In
                values: [ssd]
      preferredDuringSchedulingIgnoredDuringExecution:
        - weight: 1
          preference:
            matchExpressions:
              - key: zone
                operator: In
                values: [us-east-1a]
```

### 4. Pod Affinity/Anti-Affinity

```yaml
spec:
  affinity:
    podAntiAffinity:
      preferredDuringSchedulingIgnoredDuringExecution:
        - weight: 100
          podAffinityTerm:
            labelSelector:
              matchExpressions:
                - key: app
                  operator: In
                  values: [myapp]
            topologyKey: kubernetes.io/hostname
```

### 5. Taint 与 Toleration

```bash
# 给节点加污点
kubectl taint nodes node1 key=value:NoSchedule
kubectl taint nodes node1 key=value:NoExecute
kubectl taint nodes node1 key-
```

```yaml
spec:
  tolerations:
    - key: "key"
      operator: "Equal"
      value: "value"
      effect: "NoSchedule"
```
