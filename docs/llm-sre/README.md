# LLM SRE 专题导航

本专题面向已经完成基础 SRE、容器、Kubernetes、可观测性学习，并准备进入 LLM 推理服务运维的人。适合平台工程师、推理服务运维、AI 基础设施工程师，也适合作为从传统 SRE 过渡到 LLMOps 的补充索引。

这组文档现在已经包含三类内容：专题导航、术语与指标对齐、生命周期主教程与运行手册。它们的作用是帮助你组织学习路径、统一语言，并把训练到推理的关键运行问题串成一个可持续扩展的专题目录。

## 阅读顺序

1. [01-roadmap.md](./01-roadmap.md)：先看学习路线，明确哪些内容必须掌握，哪些适合进阶。
2. [02-glossary.md](./02-glossary.md)：建立统一术语表，避免把训练、推理、并行、监控概念混在一起。
3. [10-llm-lifecycle-overview.md](./10-llm-lifecycle-overview.md)：从生命周期视角展开训练、推理、治理与运维分工。

## 与 Day 161-172 的关系

`day161-172` 已经覆盖了 LLMOps 入门、GPU 基础设施、推理部署、指标监控、微调流水线、高可用、RAG、AI 应用监控、安全合规与综合实战。本目录不是重复写一遍，而是提供一个更稳定的主题入口：

- `day161-166` 偏基础搭建与全景认知，对应本专题的“必学”部分。
- `day167-171` 偏生产化与系统集成，对应本专题的“进阶”部分。
- `day172` 更像知识抽查与薄弱点提示，可作为术语回顾和复盘入口。

如果你已经按天学习过 `day161-172`，这里更适合做二次整理、查漏补缺和外部资料扩展；如果你还没系统学过，这里可以先帮助你决定从哪里开始读。

## 目录概览

- `README.md`：专题首页，说明目标读者、学习目标与目录结构。
- `01-roadmap.md`：学习路线图，区分必学、进阶与前沿追踪。
- `02-glossary.md`：LLM SRE 常用术语速查表。
- `03-reference-map.md`：官方文档、开源项目、论文与技术博客地图。
- `10-22`：主教程层，覆盖生命周期、训练基础设施、推理平台、RAG/Agent、安全治理与前沿方向。
- `30-32`：运行手册层，覆盖上线检查、事故处置和容量规划速查。

## 使用建议

先用路线图定范围，再用术语表对齐语言。读正文时，遇到陌生框架、指标或并行方式，先回到术语表确认它在运维中的关注点，再去参考地图找一手资料。
