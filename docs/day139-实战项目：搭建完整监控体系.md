## 🏗️ 项目

```yaml
# docker-compose.yml
version: '3.8'
services:
  prometheus:
    image: prom/prometheus
    ports: ["9090:9090"]
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml

  grafana:
    image: grafana/grafana
    ports: ["3000:3000"]

  alertmanager:
    image: prom/alertmanager
    ports: ["9093:9093"]

  node-exporter:
    image: prom/node-exporter
    ports: ["9100:9100"]
```
