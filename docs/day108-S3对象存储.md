## 📖 S3

### 1. 核心概念

```
Bucket — 存储桶（全局唯一名称）
Object — 对象（文件）
Key — 对象键（路径）
Versioning — 版本控制
Lifecycle — 生命周期策略
```

### 2. 常用操作

```bash
# 创建桶
aws s3 mb s3://my-bucket

# 上传
aws s3 cp file.txt s3://my-bucket/
aws s3 sync ./local/ s3://my-bucket/

# 下载
aws s3 cp s3://my-bucket/file.txt .

# 列出
aws s3 ls s3://my-bucket/
```

### 3. 生命周期

```json
{
  "Rules": [{
    "Id": "archive",
    "Status": "Enabled",
    "Prefix": "logs/",
    "Transitions": [{
      "Days": 30,
      "StorageClass": "GLACIER"
    }],
    "Expiration": {
      "Days": 365
    }
  }]
}
```
