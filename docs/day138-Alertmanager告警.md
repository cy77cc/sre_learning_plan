### 练习 1：ELK 日志平台

```bash
# Filebeat 配置
cat > /etc/filebeat/filebeat.yml << 'EOF'
filebeat.inputs:
  - type: log
    paths:
      - /var/log/nginx/*.log
    fields:
      service: nginx
output.elasticsearch:
  hosts: ["localhost:9200"]
EOF

# 查询示例（Kibana/ES）
curl -X GET "localhost:9200/filebeat-*/_search" -H 'Content-Type: application/json' -d'
{{
  "query": {{ "match": {{ "http.response.status_code": 500 }} }},
  "size": 10
}}'
```
