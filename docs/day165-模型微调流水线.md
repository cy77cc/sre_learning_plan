### 1. 微调方法总览

#### 1.1 微调方法对比

```
┌──────────────────────────────────────────────────────────────┐
│                    LLM 微调方法对比                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 全量微调 (Full Fine-tuning)                               │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  ┌─────────────────────────────────────┐               │ │
│  │  │         原始模型 (所有参数)           │               │ │
│  │  │  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐    │               │ │
│  │  │  │ W1│ │ W2│ │ W3│ │ W4│ │...│    │  全部更新       │ │
│  │  │  └───┘ └───┘ └───┘ └───┘ └───┘    │               │ │
│  │  └─────────────────────────────────────┘               │ │
│  │  显存需求: 参数量 × 16 bytes (FP32) 或 × 8 (FP16+优化器)│ │
│  │  70B 模型: 约 560GB 显存 (FP32) 或 280GB (FP16)        │ │
│  │  优势: 效果最好                                         │ │
│  │  劣势: 显存需求巨大，训练成本高                          │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  2. LoRA (Low-Rank Adaptation)                               │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  ┌─────────────────────────────────────┐               │ │
│  │  │  原始模型 (冻结)        LoRA 适配器   │               │ │
│  │  │  ┌───┐ ┌───┐ ┌───┐    ┌───┐ ┌───┐  │               │ │
│  │  │  │ W1│ │ W2│ │ W3│    │ A1│ │ B1│  │  只训练 LoRA   │ │
│  │  │  │冻结│ │冻结│ │冻结│    │ A2│ │ B2│  │               │ │
│  │  │  └───┘ └───┘ └───┘    └───┘ └───┘  │               │ │
│  │  └─────────────────────────────────────┘               │ │
│  │  原理: W' = W + A × B (低秩分解)                       │ │
│  │  参数量: 约原模型的 0.1% - 1%                           │ │
│  │  显存需求: 仅需存储 LoRA 参数 + 梯度                    │ │
│  │  8B 模型: 约 16-20GB 显存                               │ │
│  │  优势: 显存需求低，训练快，可叠加多个 LoRA               │ │
│  │  劣势: 效果略逊于全量微调                                │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  3. QLoRA (Quantized LoRA)                                   │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  原始模型量化为 4-bit (NF4) + LoRA 适配器 (FP16)        │ │
│  │  显存需求: 进一步降低约 50%                              │ │
│  │  70B 模型: 约 36-48GB 显存 (单张 A100 80GB 可训)        │ │
│  │  优势: 最低显存需求                                     │ │
│  │  劣势: 训练速度略慢（需要反量化）                        │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  对比总结:                                                    │
│  ┌──────────┬──────────┬──────────┬──────────┬────────────┐ │
│  │ 方法      │ 8B 显存  │ 70B 显存  │ 训练速度  │ 效果       │ │
│  ├──────────┼──────────┼──────────┼──────────┼────────────┤ │
│  │ 全量微调  │ ~128GB   │ ~2TB     │ 慢       │ 最好       │ │
│  │ LoRA     │ ~20GB    │ ~160GB   │ 快       │ 接近       │ │
│  │ QLoRA    │ ~10GB    │ ~48GB    │ 中等     │ 略逊       │ │
│  └──────────┴──────────┴──────────┴──────────┴────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

#### 1.2 LoRA 原理详解

```
┌──────────────────────────────────────────────────────────────┐
│                    LoRA 原理图解                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  原始线性层:                                                  │
│  Y = W × X                                                   │
│  W: [d × d] 矩阵 (例: 4096 × 4096 = 16M 参数)               │
│                                                              │
│  LoRA 修改:                                                   │
│  Y = W × X + (A × B) × X                                    │
│       │           │                                          │
│       │     低秩分解:                                         │
│       │     A: [d × r] (例: 4096 × 16 = 64K 参数)            │
│       │     B: [r × d] (例: 16 × 4096 = 64K 参数)            │
│       │     r << d (rank 远小于维度)                          │
│       │                                                      │
│       └─ 冻结，不更新                                         │
│                                                              │
│  参数量对比:                                                  │
│  原始: 4096 × 4096 = 16,777,216 参数                         │
│  LoRA: 4096 × 16 + 16 × 4096 = 131,072 参数 (0.78%)         │
│                                                              │
│  训练过程:                                                    │
│  1. 加载预训练模型，冻结所有参数                               │
│  2. 在 Attention 层的 Q/K/V/O 投影后添加 LoRA 适配器          │
│  3. 只训练 LoRA 的 A 和 B 矩阵                               │
│  4. 训练完成后，LoRA 权重可以合并到原始权重                    │
│     或独立保存（支持动态切换）                                 │
│                                                              │
│  关键超参数:                                                   │
│  - rank (r): 低秩维度，通常 8-64                             │
│  - alpha: 缩放因子，通常等于 rank 或 2×rank                   │
│  - target_modules: 应用 LoRA 的层（通常是 q_proj, v_proj）   │
│  - dropout: LoRA 层的 dropout 率                             │
└──────────────────────────────────────────────────────────────┘
```

#### 2.2 数据处理流程

```python
#!/usr/bin/env python3
"""data_preparation.py - 微调数据准备工具"""

import json
import random
from typing import List, Dict
from datasets import Dataset, DatasetDict

def load_jsonl(file_path: str) -> List[Dict]:
    """加载 JSONL 格式数据"""
    data = []
    with open(file_path, "r", encoding="utf-8") as f:
        for line in f:
            if line.strip():
                data.append(json.loads(line))
    return data

def validate_chat_data(data: List[Dict]) -> List[str]:
    """验证对话格式数据"""
    errors = []
    for i, item in enumerate(data):
        if "messages" not in item:
            errors.append(f"Item {i}: missing 'messages' field")
            continue
        messages = item["messages"]
        if not isinstance(messages, list):
            errors.append(f"Item {i}: 'messages' is not a list")
            continue
        for j, msg in enumerate(messages):
            if "role" not in msg:
                errors.append(f"Item {i}, Message {j}: missing 'role'")
            if "content" not in msg:
                errors.append(f"Item {i}, Message {j}: missing 'content'")
            if msg.get("role") not in ("system", "user", "assistant"):
                errors.append(f"Item {i}, Message {j}: invalid role '{msg.get('role')}'")
        # 最后一条消息应该是 assistant
        if messages[-1].get("role") != "assistant":
            errors.append(f"Item {i}: last message should be assistant")
    return errors

def tokenize_chat_data(data: List[Dict], tokenizer) -> Dataset:
    """将对话数据转换为训练格式"""
    def format_chat(example):
        text = tokenizer.apply_chat_template(
            example["messages"],
            tokenize=False,
            add_generation_prompt=False,
        )
        return {"text": text}

    dataset = Dataset.from_list(data)
    dataset = dataset.map(format_chat)
    return dataset

def prepare_dataset(
    data_path: str,
    tokenizer,
    test_size: float = 0.1,
    max_length: int = 2048,
    seed: int = 42,
) -> DatasetDict:
    """准备训练和验证数据集"""
    # 加载数据
    raw_data = load_jsonl(data_path)
    print(f"加载了 {len(raw_data)} 条数据")

    # 验证数据
    errors = validate_chat_data(raw_data)
    if errors:
        print(f"发现 {len(errors)} 个数据质量问题:")
        for err in errors[:10]:
            print(f"  - {err}")

    # 格式化
    dataset = tokenize_chat_data(raw_data, tokenizer)

    # 过滤过长的样本
    def filter_length(example):
        tokens = tokenizer(example["text"], truncation=False)
        return len(tokens["input_ids"]) <= max_length

    original_len = len(dataset)
    dataset = dataset.filter(filter_length)
    print(f"过滤后: {len(dataset)}/{original_len} 条 (max_length={max_length})")

    # 分割训练/验证集
    split_dataset = dataset.train_test_split(test_size=test_size, seed=seed)
    print(f"训练集: {len(split_dataset['train'])} 条")
    print(f"验证集: {len(split_dataset['test'])} 条")

    return split_dataset

def create_sample_sre_dataset(output_path: str, num_samples: int = 100):
    """创建示例 SRE 微调数据集"""
    templates = [
        {
            "question": "什么是{concept}？",
            "concept": ["SLO", "SLA", "SLI", "错误预算", "故障域", "降级"],
            "context": "SRE 领域",
        },
        {
            "question": "如何排查{system}的{issue}？",
            "system": ["Kubernetes Pod", "Docker 容器", "Nginx", "MySQL"],
            "issue": ["重启问题", "性能下降", "内存泄漏", "连接超时"],
            "context": "运维排查",
        },
        {
            "question": "编写一个{tool}脚本来{task}",
            "tool": ["Bash", "Python", "Terraform", "Ansible"],
            "task": ["监控 GPU 状态", "清理日志", "部署服务", "备份数据库"],
            "context": "自动化运维",
        },
    ]

    dataset = []
    for i in range(num_samples):
        template = random.choice(templates)
        # 生成示例数据（实际使用时应基于真实问答对）
        item = {
            "messages": [
                {"role": "system", "content": "你是一个资深 SRE 工程师。"},
                {"role": "user", "content": f"SRE 相关问题 {i}"},
                {"role": "assistant", "content": f"SRE 专业回答 {i}"},
            ]
        }
        dataset.append(item)

    with open(output_path, "w", encoding="utf-8") as f:
        for item in dataset:
            f.write(json.dumps(item, ensure_ascii=False) + "\n")

    print(f"生成了 {len(dataset)} 条示例数据到 {output_path}")

if __name__ == "__main__":
    create_sample_sre_dataset("sre_training_data.jsonl")
```

### 3. LoRA 微调实践

#### 3.1 使用 Hugging Face PEFT 进行 LoRA 微调

```python
#!/usr/bin/env python3
"""lora_finetune.py - LoRA 微调脚本"""

import torch
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,
    TrainingArguments,
    Trainer,
    BitsAndBytesConfig,
)
from peft import (
    LoraConfig,
    get_peft_model,
    prepare_model_for_kbit_training,
    TaskType,
)
from datasets import load_dataset
import os

# ============ 配置 ============
MODEL_NAME = "meta-llama/Llama-3.1-8B-Instruct"
OUTPUT_DIR = "./sre-lora-adapter"
LORA_RANK = 16
LORA_ALPHA = 32
LORA_DROPOUT = 0.05
TARGET_MODULES = ["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"]
MAX_LENGTH = 2048
BATCH_SIZE = 4
GRADIENT_ACCUMULATION = 4
LEARNING_RATE = 2e-4
NUM_EPOCHS = 3
USE_4BIT = True  # QLoRA

def setup_model_and_tokenizer():
    """加载模型和分词器"""
    # 量化配置 (QLoRA)
    bnb_config = None
    if USE_4BIT:
        bnb_config = BitsAndBytesConfig(
            load_in_4bit=True,
            bnb_4bit_quant_type="nf4",
            bnb_4bit_compute_dtype=torch.bfloat16,
            bnb_4bit_use_double_quant=True,
        )

    # 加载分词器
    tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME)
    tokenizer.pad_token = tokenizer.eos_token
    tokenizer.padding_side = "right"

    # 加载模型
    model = AutoModelForCausalLM.from_pretrained(
        MODEL_NAME,
        quantization_config=bnb_config,
        device_map="auto",
        torch_dtype=torch.bfloat16,
        trust_remote_code=True,
    )

    if USE_4BIT:
        model = prepare_model_for_kbit_training(model)

    return model, tokenizer

def setup_lora(model):
    """配置 LoRA 适配器"""
    lora_config = LoraConfig(
        task_type=TaskType.CAUSAL_LM,
        r=LORA_RANK,
        lora_alpha=LORA_ALPHA,
        lora_dropout=LORA_DROPOUT,
        target_modules=TARGET_MODULES,
        bias="none",
    )

    model = get_peft_model(model, lora_config)

    # 打印可训练参数统计
    trainable_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
    total_params = sum(p.numel() for p in model.parameters())
    print(f"可训练参数: {trainable_params:,} / {total_params:,} "
          f"({100 * trainable_params / total_params:.2f}%)")

    return model

def prepare_dataset(tokenizer):
    """准备训练数据"""
    # 加载数据集
    dataset = load_dataset("json", data_files="sre_training_data.jsonl")

    def tokenize_function(examples):
        # 格式化对话
        texts = []
        for messages in examples["messages"]:
            text = tokenizer.apply_chat_template(
                messages,
                tokenize=False,
                add_generation_prompt=False,
            )
            texts.append(text)

        # 分词
        tokenized = tokenizer(
            texts,
            truncation=True,
            max_length=MAX_LENGTH,
            padding="max_length",
        )
        tokenized["labels"] = tokenized["input_ids"].copy()
        return tokenized

    tokenized_dataset = dataset.map(
        tokenize_function,
        batched=True,
        remove_columns=dataset["train"].column_names,
    )

    return tokenized_dataset

def train():
    """执行训练"""
    print("=== LoRA 微调开始 ===")

    # 1. 加载模型
    print("加载模型...")
    model, tokenizer = setup_model_and_tokenizer()

    # 2. 配置 LoRA
    print("配置 LoRA...")
    model = setup_lora(model)

    # 3. 准备数据
    print("准备数据...")
    dataset = prepare_dataset(tokenizer)

    # 4. 训练参数
    training_args = TrainingArguments(
        output_dir=OUTPUT_DIR,
        num_train_epochs=NUM_EPOCHS,
        per_device_train_batch_size=BATCH_SIZE,
        gradient_accumulation_steps=GRADIENT_ACCUMULATION,
        learning_rate=LEARNING_RATE,
        weight_decay=0.01,
        warmup_ratio=0.1,
        lr_scheduler_type="cosine",
        logging_steps=10,
        save_steps=100,
        save_total_limit=3,
        evaluation_strategy="steps",
        eval_steps=100,
        bf16=True,
        gradient_checkpointing=True,
        optim="paged_adamw_8bit",
        report_to="tensorboard",
        run_name="sre-lora-finetune",
    )

    # 5. 创建 Trainer
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=dataset["train"],
        eval_dataset=dataset.get("test"),
        tokenizer=tokenizer,
    )

    # 6. 开始训练
    print("开始训练...")
    trainer.train()

    # 7. 保存 LoRA 适配器
    print(f"保存 LoRA 适配器到 {OUTPUT_DIR}")
    model.save_pretrained(OUTPUT_DIR)
    tokenizer.save_pretrained(OUTPUT_DIR)

    print("=== 训练完成 ===")

if __name__ == "__main__":
    train()
```

#### 3.2 使用 Unsloth 加速微调

```python
#!/usr/bin/env python3
"""unsloth_finetune.py - 使用 Unsloth 加速 LoRA 微调"""

from unsloth import FastLanguageModel
from transformers import TrainingArguments
from trl import SFTTrainer
from datasets import load_dataset
import torch

# Unsloth 配置
MODEL_NAME = "unsloth/Meta-Llama-3.1-8B-Instruct"
MAX_SEQ_LENGTH = 2048
LORA_RANK = 16

def main():
    # 1. 加载模型（Unsloth 优化版本，加载速度提升 2x）
    model, tokenizer = FastLanguageModel.from_pretrained(
        model_name=MODEL_NAME,
        max_seq_length=MAX_SEQ_LENGTH,
        dtype=None,  # 自动检测
        load_in_4bit=True,
    )

    # 2. 配置 LoRA（Unsloth 优化版本，训练速度提升 1.5x）
    model = FastLanguageModel.get_peft_model(
        model,
        r=LORA_RANK,
        target_modules=["q_proj", "k_proj", "v_proj", "o_proj",
                        "gate_proj", "up_proj", "down_proj"],
        lora_alpha=LORA_RANK * 2,
        lora_dropout=0,
        bias="none",
        use_gradient_checkpointing="unsloth",  # Unsloth 优化
        random_state=42,
    )

    # 3. 准备数据
    dataset = load_dataset("json", data_files="sre_training_data.jsonl")

    def format_chat(example):
        text = tokenizer.apply_chat_template(
            example["messages"],
            tokenize=False,
            add_generation_prompt=False,
        )
        return {"text": text}

    dataset = dataset.map(format_chat)

    # 4. 训练参数
    training_args = TrainingArguments(
        output_dir="./sre-lora-unsloth",
        num_train_epochs=3,
        per_device_train_batch_size=4,
        gradient_accumulation_steps=4,
        learning_rate=2e-4,
        fp16=not torch.cuda.is_bf16_supported(),
        bf16=torch.cuda.is_bf16_supported(),
        logging_steps=10,
        optim="adamw_8bit",
        weight_decay=0.01,
        lr_scheduler_type="linear",
        seed=42,
    )

    # 5. 创建 Trainer
    trainer = SFTTrainer(
        model=model,
        tokenizer=tokenizer,
        train_dataset=dataset["train"],
        dataset_text_field="text",
        max_seq_length=MAX_SEQ_LENGTH,
        args=training_args,
    )

    # 6. 训练
    trainer.train()

    # 7. 保存
    model.save_pretrained("./sre-lora-unsloth")
    tokenizer.save_pretrained("./sre-lora-unsloth")

    # 8. 合并 LoRA 到基础模型（可选）
    model.save_pretrained_merged(
        "./sre-merged-model",
        tokenizer,
        save_method="merged_16bit",
    )

if __name__ == "__main__":
    main()
```

#!/usr/bin/env python3
"""training_monitor.py - 训练过程实时监控"""

import time
import json
import subprocess
from pathlib import Path

def get_gpu_stats():
    """获取 GPU 状态"""
    result = subprocess.run(
        ["nvidia-smi", "--query-gpu=index,utilization.gpu,memory.used,memory.total,temperature.gpu,power.draw",
         "--format=csv,noheader,nounits"],
        capture_output=True, text=True
    )
    gpus = []
    for line in result.stdout.strip().split("\n"):
        parts = [x.strip() for x in line.split(",")]
        gpus.append({
            "index": int(parts[0]),
            "utilization": int(parts[1]),
            "memory_used": int(parts[2]),
            "memory_total": int(parts[3]),
            "temperature": int(parts[4]),
            "power": float(parts[5]),
        })
    return gpus

def parse_training_log(log_file: str):
    """解析训练日志"""
    metrics = []
    with open(log_file, "r") as f:
        for line in f:
            try:
                data = json.loads(line)
                if "loss" in data:
                    metrics.append(data)
            except json.JSONDecodeError:
                continue
    return metrics

def monitor_training(output_dir: str, interval: int = 30):
    """实时监控训练过程"""
    log_file = f"{output_dir}/trainer_state.json"

    print("=== 训练监控 ===")
    print(f"输出目录: {output_dir}")
    print(f"刷新间隔: {interval}s")
    print()

    while True:
        # GPU 状态
        gpus = get_gpu_stats()
        print(f"[{time.strftime('%H:%M:%S')}] GPU 状态:")
        for gpu in gpus:
            print(f"  GPU {gpu['index']}: "
                  f"Util={gpu['utilization']}% "
                  f"Mem={gpu['memory_used']}/{gpu['memory_total']}MB "
                  f"Temp={gpu['temperature']}C "
                  f"Power={gpu['power']}W")

        # 训练指标
        if Path(log_file).exists():
            try:
                with open(log_file, "r") as f:
                    state = json.load(f)
                log_history = state.get("log_history", [])
                if log_history:
                    latest = log_history[-1]
                    print(f"  训练进度: Step {latest.get('step', 'N/A')}")
                    if "loss" in latest:
                        print(f"  Loss: {latest['loss']:.4f}")
                    if "learning_rate" in latest:
                        print(f"  LR: {latest['learning_rate']:.2e}")
            except Exception as e:
                print(f"  读取训练状态失败: {e}")

        print()
        time.sleep(interval)

if __name__ == "__main__":

#### 5.2 评估脚本

```python
#!/usr/bin/env python3
"""evaluate_model.py - 微调模型评估脚本"""

import json
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel
import numpy as np

def load_model(base_model: str, lora_adapter: str = None):
    """加载模型（可选 LoRA 适配器）"""
    tokenizer = AutoTokenizer.from_pretrained(base_model)
    model = AutoModelForCausalLM.from_pretrained(
        base_model,
        torch_dtype=torch.bfloat16,
        device_map="auto",
    )
    if lora_adapter:
        model = PeftModel.from_pretrained(model, lora_adapter)
    return model, tokenizer

def evaluate_perplexity(model, tokenizer, texts: list, max_length: int = 512):
    """计算困惑度"""
    model.eval()
    losses = []

    for text in texts:
        inputs = tokenizer(text, return_tensors="pt", truncation=True,
                          max_length=max_length).to(model.device)
        with torch.no_grad():
            outputs = model(**inputs, labels=inputs["input_ids"])
        losses.append(outputs.loss.item())

    avg_loss = np.mean(losses)
    perplexity = np.exp(avg_loss)
    return {
        "avg_loss": avg_loss,
        "perplexity": perplexity,
        "num_samples": len(texts),
    }

def evaluate_sre_tasks(model, tokenizer):
    """评估 SRE 任务表现"""
    test_cases = [
        {
            "question": "什么是 SLO？",
            "keywords": ["服务级别目标", "Service Level Objective", "性能标准"],
        },
        {
            "question": "如何排查 Kubernetes Pod OOMKilled？",
            "keywords": ["内存", "limits", "requests", "kubectl describe"],
        },
        {
            "question": "解释蓝绿部署和金丝雀部署的区别",
            "keywords": ["蓝绿", "金丝雀", "流量", "回滚"],
        },
    ]

    results = []
    for case in test_cases:
        inputs = tokenizer(case["question"], return_tensors="pt").to(model.device)
        with torch.no_grad():
            outputs = model.generate(
                **inputs,
                max_new_tokens=200,
                temperature=0.7,
                do_sample=True,
            )
        response = tokenizer.decode(outputs[0], skip_special_tokens=True)

        # 检查关键词覆盖率
        keyword_hits = sum(1 for kw in case["keywords"] if kw in response)
        keyword_coverage = keyword_hits / len(case["keywords"])

        results.append({
            "question": case["question"],
            "response": response,
            "keyword_coverage": keyword_coverage,
        })

    avg_coverage = np.mean([r["keyword_coverage"] for r in results])
    return {
        "results": results,
        "avg_keyword_coverage": avg_coverage,
    }

def main():
    base_model = "meta-llama/Llama-3.1-8B-Instruct"
    lora_adapter = "./sre-lora-adapter"

    print("=== 模型评估 ===")

    # 加载微调后的模型
    print("加载微调模型...")
    ft_model, tokenizer = load_model(base_model, lora_adapter)

    # 加载原始模型（用于对比）
    print("加载原始模型...")
    base_model_obj, _ = load_model(base_model)

    # 测试数据
    test_texts = [
        "SRE 的核心原则是通过工程方法解决运维问题。",
        "Kubernetes 是一个容器编排平台，用于自动化部署和管理容器化应用。",
    ]

    # 评估困惑度
    print("\n--- 困惑度评估 ---")
    base_ppl = evaluate_perplexity(base_model_obj, tokenizer, test_texts)
    ft_ppl = evaluate_perplexity(ft_model, tokenizer, test_texts)
    print(f"原始模型 Perplexity: {base_ppl['perplexity']:.2f}")
    print(f"微调模型 Perplexity: {ft_ppl['perplexity']:.2f}")

    # 评估 SRE 任务
    print("\n--- SRE 任务评估 ---")
    base_eval = evaluate_sre_tasks(base_model_obj, tokenizer)
    ft_eval = evaluate_sre_tasks(ft_model, tokenizer)
    print(f"原始模型关键词覆盖率: {base_eval['avg_keyword_coverage']:.2%}")
    print(f"微调模型关键词覆盖率: {ft_eval['avg_keyword_coverage']:.2%}")

    # 输出详细结果
    print("\n--- 详细结果 ---")
    for r in ft_eval["results"]:
        print(f"Q: {r['question']}")
        print(f"A: {r['response'][:200]}...")
        print(f"关键词覆盖: {r['keyword_coverage']:.2%}")
        print()

if __name__ == "__main__":
    main()
```

## 🎯 面试题精选

### 1. LoRA 和全量微调有什么区别？各自适用于什么场景？

**参考答案**：
- **全量微调**：更新模型所有参数。显存需求大（70B 模型需要 2TB+），但效果最好。适用于有充足计算资源且需要最大化模型性能的场景。
- **LoRA**：只训练低秩适配器（约 0.1% 参数）。显存需求小（8B 模型约 20GB），训练快，可叠加多个适配器。适用于资源有限、需要快速迭代、或多任务场景。

选择建议：
- 有充足 GPU + 需要最佳效果 -> 全量微调
- GPU 有限 + 快速迭代 -> LoRA
- 单张 GPU + 大模型 -> QLoRA

### 2. 什么是 QLoRA？它如何进一步降低显存需求？

**参考答案**：
QLoRA = Quantized LoRA，将基础模型量化为 4-bit（NF4 格式），然后在量化模型上进行 LoRA 微调。

关键技术：
1. **NF4 量化**：4-bit NormalFloat，专为正态分布权重设计的量化格式
2. **双重量化**：对量化常数再进行量化，进一步节省显存
3. **分页优化器**：使用 CPU 内存处理显存峰值

效果：70B 模型从需要 160GB（LoRA）降到 48GB（QLoRA），单张 A100 80GB 即可微调。

### 3. 如何判断微调是否过拟合？如何预防？

**参考答案**：
判断过拟合：
- 训练损失持续下降，但验证损失开始上升
- 模型在训练集上表现很好，但在新问题上表现差
- 生成内容开始"背诵"训练数据而非理解回答

预防方法：
1. **数据方面**：增加数据多样性，数据增强，确保数据质量
2. **正则化**：使用 dropout（LoRA dropout 0.05-0.1），weight decay
3. **早停**：监控验证损失，连续 N 步不下降就停止
4. **降低模型容量**：减小 LoRA rank
5. **交叉验证**：使用 k-fold 交叉验证评估泛化能力

### 4. DeepSpeed ZeRO 的三个阶段分别做了什么？

**参考答案**：
- **Stage 1**：分片优化器状态。每个 GPU 只存储 1/N 的优化器状态（Adam 的 m 和 v），参数和梯度仍然完整存储。显存节省约 4 倍。
- **Stage 2**：在 Stage 1 基础上，分片梯度。每个 GPU 只存储 1/N 的梯度。显存节省约 8 倍。
- **Stage 3**：在 Stage 2 基础上，分片参数。每个 GPU 只存储 1/N 的参数，需要时通过 AllGather 通信获取完整参数。显存节省约 N 倍（N = GPU 数量）。

选择：Stage 2 是最常用的平衡点（显存节省大，通信开销适中）。Stage 3 适用于模型特别大的场景。

### 5. 微调数据的质量和数量哪个更重要？

**参考答案**：
**质量更重要**。研究表明：
- 1000 条高质量数据的微调效果可能优于 10 万条低质量数据
- 数据质量差会导致模型学到错误的模式（"垃圾进，垃圾出"）

高质量数据的特征：
- 回答准确、完整、专业
- 覆盖目标任务的多样性
- 格式一致、无噪声
- 来自领域专家或经过人工审核

数据量的建议：
- LoRA 微调：1000-10000 条高质量数据通常足够
- 全量微调：需要更多数据（10 万+）
- 数据量超过一定阈值后，质量的边际收益递减
