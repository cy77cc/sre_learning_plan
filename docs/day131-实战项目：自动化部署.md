> ⏰ 计划学习时间：2-3 小时

---

## 🏗️ 项目

```yaml
- name: Deploy Web Application
  hosts: web
  become: yes
  roles:
    - common
    - nginx
    - app

  tasks:
    - name: Pull latest code
      git:
        repo: "https://github.com/example/app.git"
        dest: /opt/app
        version: main

    - name: Restart app
      systemd:
        name: myapp
        state: restarted
```
